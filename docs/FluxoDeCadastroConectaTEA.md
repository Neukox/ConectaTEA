# Fluxo de Cadastro ConectaTEA

## Passo 1: O Cadastro Clínico Provisório (Início pelo Profissional)

Nesta etapa, o profissional de saúde mental toma a iniciativa para não depender de uma conta ativa do pai no primeiro momento.

- Entrada de Dados: O profissional acessa a área de "Cadastro de crianças" para acompanhamento clínico estruturado.
- Informações Básicas: Inserção de dados essenciais como nome, data de nascimento e, se necessário, informações diagnósticas preliminares para uso interno.
- Finalidade Imediata: Este registro permite o uso imediato do Dashboard centralizado e do espaço para gerenciamento das sessões clínicas.
- Status do Perfil: O perfil da criança é criado com o status de "Aguardando Vínculo Familiar".
- Privacidade: Os dados funcionam como um prontuário digital privado do profissional dentro da plataforma.

## Passo 2: Geração da Chave de Conexão (Token/QR Code)

A plataforma cria uma "ponte" segura entre o cadastro da criança e o responsável.

- Identificador Único: O sistema gera automaticamente um Código Alfanumérico Único e um QR Code exclusivo para a ficha da criança.
- Entrega do Convite: O profissional fornece o código ou QR Code ao pai/responsável (impresso, por mensagem ou via tela do consultório).
- Segurança: Este código impede que dados sensíveis fiquem expostos em buscas públicas, sendo a única forma de vincular o responsável à ficha específica.

## Passo 3: Onboarding do Responsável e Consentimento Legal

O fluxo passa para o pai, que utilizará a plataforma para acompanhamento à distância.

- Criação de Conta: O responsável cria seu perfil individual na ConectaTEA.
- Barreira Jurídica (LGPD): O sistema apresenta o Termo de Consentimento obrigatório.
- Aceite Formal: O pai deve autorizar formalmente o tratamento de seus dados e os do menor, além da visualização pelo profissional solicitante.
- Vinculação Direta: O pai utiliza a opção "Vincular Criança" para escanear o QR Code ou inserir o código fornecido.

## Passo 4: Sincronização e Divisão de Visualizações

O sistema reconhece o vínculo, tornando a conta do pai e a ficha do profissional uma unidade sincronizada com acessos distintos:

**O que o Pai Visualiza:**

- Dashboard de Desenvolvimento: Gráficos e estatísticas de progresso.
- IA de Auxílio: Assistente de IA para orientações e análise de evolução.
- Rede Social: Grupos de apoio e comunidades internas.

**O que o Profissional Visualiza:**

- Gestão Clínica: Detalhes técnicos e registros de evolução.
- Metas Individuais: Definição e acompanhamento de metas técnicas
- Networking: Chat interno para discussões de caso com outros profissionais (se autorizado).

## Passo 5: Continuidade e Gestão de Permissões

- Propriedade do Dado: Juridicamente, o pai detém a tutela do perfil.
- Portabilidade: Em caso de mudança de profissional, o pai mantém o histórico da criança, podendo desvincular o antigo acesso e vincular um novo.
- Comunicação Direta: Habilitação total do chat interno para trocas constantes entre pais e profissionais.
