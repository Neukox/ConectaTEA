# Componentes de Vinculação de Criança

Este diretório contém todos os componentes necessários para o fluxo de vinculação de criança no ConectaTEA.

## 📁 Estrutura

```
VinculacaoCrianca/
├── QRCodeScanner.tsx        # Escaneia QR codes usando câmera
├── CodigoInput.tsx          # Input para código alfanumérico
├── ConfirmacaoVinculo.tsx   # Exibe dados da criança
├── TermoConsentimento.tsx   # Modal do termo LGPD
├── Stepper.tsx              # Indicador de progresso
└── VincularCriancaModal.tsx # Modal rápido de vinculação
```

## 🎯 Componentes

### QRCodeScanner
Componente que captura QR codes usando a câmera do dispositivo.

**Props:**
```typescript
interface QRCodeScannerProps {
  onCodeDetected: (code: string) => void
  loading: boolean
}
```

**Uso:**
```tsx
<QRCodeScanner 
  onCodeDetected={(codigo) => console.log(codigo)}
  loading={false}
/>
```

**Funcionalidades:**
- ✅ Acesso à câmera do dispositivo
- ✅ Preview ao vivo
- ✅ Tratamento de erros de permissão
- ✅ Botão de captura manual
- ✅ Estados de carregamento

### TermoConsentimento

**Props:**
```typescript
interface TermoConsentimentoProps {
  onAceitar: () => void

  consentimentoAceito: boolean
```

**Uso:**

**Seções do Termo:**
1. Coleta de Dados
2. Uso dos Dados
3. Compartilhamento de Dados
4. Direitos do Responsável
5. Segurança de Dados

### VincularCriancaModal
Modal compacto para vinculação rápida.

**Props:**
```typescript
interface VincularCriancaModalProps {
  isOpen: boolean
  onClose: () => void
  onVinculoConfirmado?: () => void
}
```

**Uso:**
```tsx
const [modalOpen, setModalOpen] = useState(false)

<button onClick={() => setModalOpen(true)}>
  Vincular Criança
</button>

<VincularCriancaModal
  isOpen={modalOpen}
  onClose={() => setModalOpen(false)}
  onVinculoConfirmado={() => {
    console.log('Vínculo confirmado!')
    setModalOpen(false)
  }}
/>
```

**Funcionalidades:**
- ✅ Overlay escuro
- ✅ Fechar ao clicar no X
- ✅ Input de código
- ✅ Dicas de ajuda

## 🔌 Integração com APIs

Os componentes trabalham com a API de vinculação:

```typescript
import { vinculacaoAPI } from '@/api/protected/axiosVinculacao'

// Validar código
const crianca = await vinculacaoAPI.validarCodigo('TEA-6081-Z')

// Confirmar vínculo
const vínculo = await vinculacaoAPI.confirmarVinculo({
  crianca_id: 1,
  consentimento_aceito: true
})

// Obter vínculos
const vinculos = await vinculacaoAPI.obterVinculos()

// Desvincular
await vinculacaoAPI.desvincularCrianca(1)
```

## 🐛 Troubleshooting

### Câmera não funciona
- Verificar permissões de câmera do navegador
- Tentar em HTTPS (câmera requer contexto seguro)
- Atualizar navegador

### Código não validar
- Verificar se o código foi copiado corretamente
- Confirmar se o código ainda é válido (30 dias)
- Verificar conexão com API

### Modal não abre
- Verificar state de `isOpen`
- Confirmar se está sendo passado corretamente
- Verificar z-index do modal
