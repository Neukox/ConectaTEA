# Inventário

O monorepo contém backend NestJS/Prisma (114 arquivos), frontend React/Vite (252 arquivos), documentação, automações GitHub e Compose. O legado permanece em `Backend/`; o novo serviço está em `BackendJava/`.

Módulos encontrados: autenticação, usuários, profissionais, crianças, vinculação/tokens/consentimento, metas/progresso, sessões, dashboard, conexões, auditoria e compatibilidade `/private`.

Foram inspecionados controllers, services, DTOs, guards, schema e migrations Prisma, clientes/serviços/tipos/schemas do frontend, rotas, contextos e documentos do projeto.
