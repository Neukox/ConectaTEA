## Fluxo de Uso

### 1. Responsável acessa a página
```
/responsavel/vincular-crianca
```

### 2. Escolhe método
- 📱 Escanear QR Code
- ⌨️ Inserir Código (TEA-XXXX-X)

### 3. Valida criança
- API: `GET /vinculacao/validar/{codigo}`

### 4. Confirma dados
- Exibe nome, idade, diagnóstico
- Verifica se está correto

### 5. Aceita termo LGPD
- Lê termo com 5 seções
- Marca checkbox obrigatório

### 6. Confirma vínculo
- API: `POST /vinculacao/confirmar`
- Sucesso!

## Próximos Passos para Backend

### Endpoints Necessários

```typescript
// Validar código/QR code
GET /api/vinculacao/validar/{codigo}
Response: {
  id: number
  nome: string
  data_nascimento: string
  diagnostico: string
  status: string
}

// Confirmar vinculação
POST /api/vinculacao/confirmar
Body: {
  crianca_id: number
  consentimento_aceito: boolean
}
Response: {
  id: number
  crianca_id: number
  responsavel_id: number
  status: string
  data_vinculo: string
}

// Obter vínculos
GET /api/vinculacao/meus-vinculos
Response: Array<Crianca>

// Desvincular
DELETE /api/vinculacao/crianca/{crianca_id}
```
